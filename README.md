# Импорт и обновление справочников

## Описание проекта
Проект представляет собой веб-интерфейс для импорта и обновления данных справочника в базе данных сайта. Пользователи загружают CSV-файл с данными, содержащими "Код" и "Название". Данные сохраняются в базе, причем обновление происходит по уникальному значению "Код". Если в названии обнаруживаются недопустимые символы, запись не сохраняется, и пользователю возвращается отчет об ошибках в формате CSV.

## Стек технологий
- Backend: PHP (без использования фреймворков)
- Database: MySQL
- Frontend: HTML + Vue.js

## Основные требования
- Импорт данных из CSV:
    - Формат файла: Код, Название.
    - "Код" является уникальным значением.
    - "Название" может содержать буквы (русские и английские), цифры, символы "-" и ".".
    - Если "Название" содержит недопустимые символы, строка не сохраняется, а в отчете выводится ошибка.

- Функционал обновления и вставки данных:
    - Если "Код" уже существует, запись обновляется.
    - Если "Код" отсутствует, запись добавляется.

- Отчет об ошибках:
    - Формируется CSV-отчет после завершения обработки. 
    - В отчете содержится исходный "Код" и "Название" из файла, а также колонка Error с сообщением об ошибке, если в "Название" присутствуют недопустимые символы.
    - Если ошибок нет, колонка Error остается пустой.
    - Отчет автоматически загружается после окончания обработки.

- Фронтенд:
    - Реализовать на Vue.js интерфейс для загрузки файла.
    - Реализовать drag-and-drop для загрузки файла, индикатор прогресса загрузки.
    - Валидация формата CSV на клиенте до отправки файла на сервер.

- Асинхронная обработка файла:
    - Использовать AJAX для асинхронной отправки файла на сервер и получения отчета.
    - Обновление статуса загрузки в реальном времени с отображением процесса для пользователя.

- Оптимизация производительности:
    - Обработка файла построчно для избежания переполнения памяти при больших объемах данных.
    - Обновление данных в базе с помощью транзакций для целостности и согласованности данных.
